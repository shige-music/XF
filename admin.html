⚠️ 管理员使用说明

1. 生成 GitHub Personal Access Token：

  1. 访问：GitHub Token 设置
  2. Note 填写：music-admin
  3. Expiration 选择：No expiration
  4. 勾选权限：repo（完整勾选）
  5. 点击 Generate token
  6. 复制生成的 Token（格式：ghp_xxxxxxxxxx）

2. Token 保存在浏览器本地，不会上传到服务器

3. 普通用户访问播放器无需 Token
